# 👑 Secret Birthday Surprise App ❤️

An interactive, responsive, and beautifully designed web application built with **Streamlit** to celebrate a special birthday surprise. Features custom CSS animations, password protection, floating effects, and interactive romantic mini-games!

---

## ✨ Features

* 🔒 **Password Protected:** Strictly confidential access for the birthday girl (`vivanishika`).
* ⌛ **Days Together Counter:** Dynamically calculates days of happiness starting from April 26, 2025.
* 💌 **Interactive Secret Envelope:** An openable love letter card with custom animation effects.
* 🎁 **Mystery Gift Unwrapper:** Interactive digital gift box that reveals cute love compliments.
* 🎮 **Couple Quiz Game:** A fun interactive quiz to test compatibility and memories.
* 🎯 **Romantic Spin Wheel:** A fortune wheel game that awards fun redeemable love vouchers.
* 🎈 **Celebration Effects:** Automated balloons, snow effects, and hidden romantic background audio.
* 📱 **Mobile & Desktop Friendly:** Divided into clean, easy-to-navigate tabs for maximum scannability.
